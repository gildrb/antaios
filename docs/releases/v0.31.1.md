# Antaios 0.31.1

Antaios 0.31.1 hardens release-host upgrades when the tracked minimum SBCL version changes.

- Clear inherited `ANTAIOS_SBCL` and `ANTAIOS_SBCL_SOURCE_ROOT` bindings before candidate bootstrap, check, and probe processes.
- Let each candidate select or install a runtime that satisfies its own tracked minimum instead of remaining pinned to the active deployment's older runtime.
